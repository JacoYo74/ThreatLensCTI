# ThreatLens-CTI

A Python-based Cyber Threat Intelligence analysis and automation project.

## Overview

ThreatLens-CTI is a practical Cyber Threat Intelligence (CTI) project designed to explore how threat data can be collected, structured, analysed and transformed into useful intelligence.

The project focuses on applying CTI concepts to realistic security investigations while developing practical skills in Python, data analysis, threat research and security automation.

## Objectives

ThreatLens-CTI aims to:

- Analyse structured cyber threat intelligence
- Identify and extract Indicators of Compromise (IOCs)
- Investigate and enrich threat indicators
- Map observed activity to MITRE ATT&CK techniques
- Analyse vulnerabilities and their associated risk
- Prioritise threats using multiple intelligence sources
- Automate repetitive CTI analysis tasks
- Generate structured threat intelligence reports

## Key Areas

### Cyber Threat Intelligence

The project explores:

- Threat actors
- Campaigns
- Indicators of Compromise (IOCs)
- Tactics, Techniques and Procedures (TTPs)
- Threat assessment
- Intelligence reporting

### MITRE ATT&CK

Threat activity will be mapped to relevant MITRE ATT&CK tactics and techniques to provide additional context around adversary behaviour.

### Vulnerability Intelligence

ThreatLens-CTI will investigate vulnerability information and explore how factors such as exploitation status and threat intelligence can be used to support prioritisation.

### Security Automation

Python will be used to automate repetitive analysis tasks and transform raw security data into structured information that can be investigated and reported.
